## 1. 建立低成本代理与分析素材
使用FFmpeg制作缩小视频和单声道16kHz音频，分析用代理，剪映链接原片。示例（替换HOST为实际文件完整路径）：
```powershell
ffprobe -v error -show_format -show_streams -of json "HOST" > "LOCAL_ONLY_SOURCE"
ffmpeg -i "HOST" -vn -ac 1 -ar 16000 "LOCAL_ONLY_SOURCE"
ffmpeg -i "HOST" -vf "scale=960:-2" -c:v libx264 -preset fast -crf 28 -c:a aac "LOCAL_ONLY_SOURCE"
```
可变帧率素材先校验音画同步；若转为恒定帧率，必须保留源时间到代理时间映射，不直接拿错时间轴去切原片。

## 2. 转写和画面双通道分析
- ASR保存句/词级时间戳、原句、置信信息；低置信标记待复核。中文模型用实际2分钟片段测试，CPU先small，资源允许再比较更大模型。
- 全片每5秒抽帧只用于粗定位训练章节，不能据此数动作次数。运动开始/结束附近加密到每0.5—1秒抽帧，并回放完整视频确认边界。
- 记录事件：进入器械区、热身、训练组、组间休息、换片、补水、闲聊、收尾。动作名称、重量、次数只引用可见或可听信息；不清楚就写“待确认”。
- “安静”不等于“无效”：无口播的完整组、呼吸、器械声都是主体。静音检测只产生候选，不执行删除。

## 3. AI输出剪辑决策表（EDL），暂不直接写草稿
每行：源文件、源起止秒、章节、动作/组号、keep/drop/speed、倍速、理由、画面/声音证据、置信度、保护段、人工批准。所有时间都是原片绝对秒。

项目里的“剪辑决策空表.csv”和“剪辑计划模板.json”没有任何真实原片时间，必须依据素材填充。训练组设protected=true，默认keep、1倍速。决策必须覆盖每条原片的完整时间范围，显式标记drop，避免遗漏段默默消失。

## 4. 下饭长片节奏规则（编辑建议，不是训练指导）
| 内容 | 默认处理 |
|---|---|
| 每个训练组 | 从准备稳定、开始动作，到结束放下器械，全组保留；切点前后留0.5—2秒呼吸余量 |
| 热身与第一组 | 留出建立场景和动作感的时间，不一上来就疲劳高光 |
| 组间休息 | 保留喘息、吐槽、互动、换重量；过长重复等待可删一部分或2—4倍速 |
| 安静但在训练 | 完整保留；不因ASR为空删除 |
| 调机位、镜头遮挡、离场后无事件 | 作为候选删段，先审阅边界是否包含动作准备或结尾 |
| 重复动作组 | 完整记录目标下默认全部保留；若确需压缩，只对已批准段变速并标“该段加速” |
| 重量和次数变化 | 保留变化上下文；字幕注明“以实际记录为准”，不编数字 |
| 闲聊和笑点 | 留足前因后果，不剪成只有一句话的突兀插播 |

长片用章节牌、动作名/组次、小量进度信息，避免每两秒特效和强BGM。器械声、脚步、喘息保留；音乐低于人声，谈话时减弱。不以情绪音乐伪造训练结果。

## 5. 人工审阅门槛
- 每个训练组起止逐一回放。组内不跳切，不误删最后一两次动作。
- 对“drop”“speed”和置信度低于0.8的候选全部审核；0.8只是本项目阈值，不是准确率承诺。
- 至少先做一个动作章节/3—5分钟样段：自然呼吸、动作连续、字幕可读、音画同步确认后再全片。
- 先导出“修改前→拟删段→修改后”的审阅清单，approved=true才进入草稿。模型的自评不自动等于批准。

## 6. 剪映衔接：需要工程，不只有MP4
新建一个独立草稿，视频主轨引用原片的source_timerange；时间线位置为target_timerange。背景音乐、字幕、章节文字分轨；视频片段可继续拖边、恢复删除前后素材、调整倍速。只导出一个压平MP4再导入剪映，不等于保留原始剪辑工程。

[pyJianYingDraft官方README](https://github.com/GuanYixuan/pyJianYingDraft)当前表格报告新版10.8的基础音视频和文本支持；模板读取与自动导出存在版本差异。优先从零创建新草稿，先验证本机版本，不依赖旧版“自动点导出”。该项目不是剪映官方公共API。

### 版本验收
1. 在剪映设置查真实草稿位置、记录版本号；备份已有草稿索引。
2. 先生成一个全新名字的10秒小工程，不覆盖已有草稿。
3. 在本机剪映打开它，拖动片段边缘、修改文字、保存、关闭再打开。
4. 人工导出并检查播放、音轨与分辨率。全部通过后再生成长片。
5. 草稿保存位置和素材位置分开。原片不移动，或者建立稳定素材目录并同步修正引用。

### 核心适配代码（需在本机安装版本上实测）
```python
import pyJianYingDraft as draft
from pyJianYingDraft import trange
folder = draft.DraftFolder(r"HOST")  # 剪映设置中的真实草稿根目录
script = folder.create_draft("健身长片-新建测试", 1920, 1080)
script.add_track(draft.TrackType.video)
# 单位是微秒；source选原片区间，target放到成片时间线
start, end, cursor = 12.0, 22.0, 0.0  # 仅示例，不是用户素材的切点
segment = draft.VideoSegment(r"HOST.mp4",
    trange(round(cursor*1_000_000), round((end-start)*1_000_000)),
    source_timerange=trange(round(start*1_000_000), round((end-start)*1_000_000)))
script.add_segment(segment)
script.save()
```
以上是10秒概念验证代码，不是已经生成的用户草稿。长片还需实现已批准EDL逐段拼接、帧边界吸附、变速后的时长、字幕映射、原片声音保留与引用路径验证。字幕必须按剪后时间重排，不能直接导入原片SRT：片段内目标时间=目标片段起点+(源字幕时间-源片段起点)/speed，跨剪口字幕切开。

## 7. 成片验收与回退
交付：可编辑剪映草稿及素材清单、审核过的EDL、章节表、可编辑SRT、预览MP4和最终MP4。逐组检查动作完整；检查全片有意的黑场与异常黑帧、声音削波、长静音、字幕/画面错位，开头中间结尾及所有切点回看。自动检测不能代替回看。

先“另存为”保留初剪；需要回退时打开初剪副本或者按EDL恢复源区间。原片从始至终不改。不要覆盖自己的微调版本；AI重跑输出新的草稿名字。
