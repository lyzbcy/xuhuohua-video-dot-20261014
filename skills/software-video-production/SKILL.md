# 软件宣传短视频制作

把真实功能拍成观众愿意继续看的视频。功能可信、画面可读、叙事有变化，与有创意的视听表达同时成立；编码成功只算技术检查。

## 接手入口

先读当前项目的 `SKILL.md` 和 [docs/agent.md](docs/agent.md)，找到当前交付、用户评价和本次相关模块。只读需要的文档。

这是v0.5.7的公开便携快照；历史本机路径标为LOCAL_ONLY_SOURCE，仅指来源，云端不依赖。规范均在本包相对目录。版本见[version.json](version.json)，本次健身适配优先读[项目Skill](../../SKILL.md)。技术工具为Python、FFmpeg/ffprobe；图形、配音、音乐和生成素材按实际任务选用，不固定渲染框架或视觉模板。

## 制作判断

1. **先确认真实演示。** 看完整事件、声音和设备关系，记录功能与源时间；不从缩略图猜“无感”“截图”“投影”的含义。保留原片，先判断隐私范围。
2. **先解决前几秒。** 开场直接给异常、问题或结果，让观众想看下一秒。用户要求署名时，放在钩子画面的次要层级；不默认先播身份片头。
3. **用范例落实表达。** 先按 [docs/exemplars.md](docs/exemplars.md) 从[片段库](examples/INDEX.md)选适合本次问题的主参考，播放片段、读对应拆解卡，将具体秒数和迁移方式写入制作记录，再按 [docs/creative.md](docs/creative.md)设计。先用自己的原片做代表片段对照，再扩展全片。重点学习剪辑、动效与声音，人工作品同样适用；不能用生视频模型的镜头画质代替剪辑参考。旧卡片布局不是默认模板，软件功能由真实画面证明。
4. **打码保留体验。** 按 [docs/privacy.md](docs/privacy.md) 遮工作文档、聊天正文和敏感标识，保留播放器、窗口轮廓、桌面与操作关系。变更镜头和构图后重新核查。
5. **声音和运动一起编排。** 按 [docs/audio.md](docs/audio.md) 配音、配乐和对齐事件。原创器乐、带唱歌曲、TTS 是不同产物，按真实能力命名。
6. **分别验收。** 按 [docs/delivery.md](docs/delivery.md) 检查媒体、功能、隐私、移动端阅读和审美。用 [scripts/media_check.py](scripts/media_check.py) 做媒体检查；技术通过不能判为优秀。
7. **交付后沉淀。** 按 [docs/evolution.md](docs/evolution.md) 写案例、归因和下次试验，更新模块与进度。用户说本次基本完成，就归档，不擅自重新剪辑或发布。

执行与目录见 [docs/workflow.md](docs/workflow.md)；重建或排障见 [docs/tech.md](docs/tech.md)；接手进度见 [docs/roadmap.md](docs/roadmap.md)。

## 当前系列已知偏好

这些来自捞鱼软件宣传系列，不能覆盖其他用户或当次另有要求的项目。

- 直接用功能钩子开场，比独立模型署名片头好。
- 真实屏幕、桌面和操作细节要清晰，不能把背景糊成低清画面。
- 固定大标题、卡片切换、轻推拉和几种转场，即使能动，也可能像 PPT/HTML PPT。
- 下一次需要更多自由发挥与视听创意；不必每条复用深色黄字界面。
- 安装口令可只放屏幕供截图，用户要求不读就不朗读。链接限制、署名和获取渠道按当次要求，不固化成所有视频的配置。

依据：[2026-10-14 桌脚看电视案例](docs/cases/2026-10-14-desk-tv.md)。用户评价为**合格**，视觉表现尚未达到期望；是经验样本，不是优秀视觉模板。

## 边界

- 不修改、安装或发布所宣传的软件，除非任务包含该动作。
- 剪辑授权不包含代发平台、发送消息、支付或购买音乐服务。
- 创意画面不冒充真实操作，不夸大兼容、隐私保护或安装成功率。
- 文字检测、抽帧和音量指标不等于逐帧隐私保证、完整试听或用户审美认可。
- 案例脚本包含特定坐标与素材路径，仅供研究。换素材必须重建时间轴和遮罩。

## 自动续火花最终反馈

自动续火花首版20分，改版与封面最终 **72分**，用户确认已在抖音/B站/小红书发布。用户喜欢微信精选表情和封面；明确指出表情上下机械摆动、像素场景质量差距和音效不足。后续读[案例](docs/cases/2026-10-15-xuhuohua.md)与creative/audio模块，以有起因和反馈的表情动作、完整像素短场景和关键事件音效改进。72分不代表优秀动画SOP已验证。该项目依用户要求已删除工程，只保留成片/封面与轻量归档，不再寻找已清理的工程文件。


## 私人日常v2：80分认可

用户认可本轮RPG小动画，整片80分；下一次动画任务先看[RPG01可播放范例与拆解](examples/cards/RPG01.md)，学习目标、行走、交互、反馈和回接真人的关系。系列视频默认考虑用户精选表情；字幕在实际手机尺寸检查。具体边界见[案例](docs/cases/2026-10-15-daily.md)，不能把私人片80分转成广告表现评分。

## 一键投递：68分最终采用

宣传v2为60分，v3开头被否定；v4将真人精彩片段前置并补双领取，用户给 **68分，明确最终采用**。钩子有帮助，音效少、缺亮点仍未解决；歌曲下次按场景试验，不能当作必加项或成熟SOP。封面一眼看懂重点，减少杂乱；多比例独立构图。读[案例](docs/cases/2026-10-15-one-click.md)和[交付](docs/delivery.md)。最终采用不等于优秀或留存提升已验证。
