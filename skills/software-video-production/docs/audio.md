# 声音、原创音乐与屏幕口令

现状：TTS、器乐合成及混音已有案例；本轮已生成下载带唱歌曲，用户选择松弛男声，日常v1获用户75分；v2加入轻游戏音效，用户评分80分，Agent未耳听。带唱任务读[生成与下载经验](music-generation.md)。
维护人：当前制作 Agent。
最后更新：2026-10-15。

## 选择声音的作用

并非每条都连续旁白。可讲述、反应、音乐驱动或保留原声操作；音效回应动作和变化，不是每张卡片同一种提示音。

原片人声先了解其价值；不在未了解内容时默认丢掉用户表达。

软件演示的讲解不足时，配乐不能充当信息。用户允许补配音后，可用通用声线串联真实功能与操作，保留有价值的创作者原话，明确合成声范围。唱词差但用户喜欢曲调时，可保留已选曲的伴奏，把解释交还给旁白；不能因更换音源删掉歌词字幕后仍沿用长音乐空段。详见[一键投递60分案例](cases/2026-10-15-one-click.md)。情绪片或可读的无旁白操作段按内容留白，不把这次修订变成所有视频持续说话的规则。

## 配音与字幕

- 自然语气与节奏优先，避免朗读整份功能清单。
- 使用音频真实时间戳、短语义字幕，检查手机换行和安全区。
- 缓存对应文本、音色、语速；改文案重新生成相应音频/字幕。
- 增减片头后检查首句、字幕、动作音效和节拍。
- 口播夸张不能新增能力承诺，尤其是绝对兼容、保证隐私与安装成功率。

## 如实命名产物

| 实际产物 | 可以称呼 | 不可冒称 |
| --- | --- | --- |
| 编音符并合成鼓、贝斯、旋律 | 原创电子/器乐配乐 | 已生成带唱 AI 歌曲 |
| TTS 朗读 | AI 配音/旁白 | 原创歌手演唱 |
| 音乐服务生成旋律、唱词、演唱 | 按结果称带唱原创歌曲 | 只写歌词或未调用服务也说歌曲完成 |

用户要求带唱时核实可用服务/插件与授权。可以先完成歌词、曲风和音画方案，未生成音频就不称歌曲交付；不擅自付费、购买订阅或发布。

记录音乐来源与授权/生成服务限制，不承诺平台一定不会静音或限流。

## 节奏与混音

声音设计可先打开[SD01片段与听辨任务](../examples/cards/SD01.md)。它保留原音轨，但当前入库Agent未耳听，尚未认定为优秀听感标杆。制作时用同一段“音乐+人声”和“加入事件声”对照试听，学习前景/环境/过渡的作用，不只数音效。其他参考的音乐踩点也需实际试听才能下结论。

关键按键、揭晓、回切、投影对照标到声音时间轴。音乐与剪辑互相影响，不只是循环旋律。旁白下压配乐，截图停留可适当抬音乐。

正常速度试听辅音、段间空白、尾音、音量突变和高频音效。约 -14 至 -18 LUFS、真峰值留余量可作短片参考，听感与平台要求优先；指标不能证明自然好听。

## 获取口令

本次要求豆包口令只展示、不读，新项目按当前要求。用易读字号、明确步骤和稳定停留供截图；时长按阅读需求，不固化每条都 12 秒。

本次口令：

> 请去 GitHub 下载「捞鱼软件中心」，再通过软件中心，帮我下载并安装「捞鱼桌脚看电视」。

视频/正文无网址，保留粉丝群、豆包两渠道。其他项目重新核实渠道、产品名与链接约束。

## 72分反馈：音效不足

自动续火花用户评分72分并明确“音效也没有多少”。有配乐与响度合格不能替代音效设计。

下次按关键事件画音效点：提醒/意外、反应、动作触发、落地/恢复；声音区分材质与情绪，并与动作起止对应。密度有变化，保留静默，避免统一转场声或每字一响。人声、音乐、音效分层，重点对白时避让，检查相邻事件叠加的峰值。

先做一个带动作与关键音效的代表段落正常速度看听，再扩展。不能耳听时如实记录，数值与ASR不能宣称听感达标。上述改法尚待下一条作品验证，不返工本次已发布成片。
