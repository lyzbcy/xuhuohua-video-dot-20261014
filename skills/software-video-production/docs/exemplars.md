# 用剪辑范例约束一次具体选择

2026-10-16公开便携快照：5个第三方作品的来源与具体秒数拆解，另附1个原创RPG可播放短片；第三方视频副本不随公开包携带。入口：[范例索引](../examples/INDEX.md)、[播放器](../examples/gallery.html)、[机器目录](../examples/catalog.json)。下文对六个短片的核验描述是本机原库记录，不代表本公开包实际包含六个视频。

## 先选对学习对象

本系列是 **AI剪视频**。优先找成片的剪辑、动态图形、界面动作和声音设计，人工制作同样适用。主要靠生视频模型生成镜头美感的AI短片不进入本库主参考。可用宣传片、广告、文字MV、动态设计作品或明确展示成片效果的声音拆解；不用工具教学标题代替成片质量。

按本次问题选一个主参考，必要时再选一两个补充。不要把多个作品的配色、转场、字体全混到一条片。

| 当前问题 | 先看片段 | 只学什么 |
| --- | --- | --- |
| 每页一样、节奏像PPT | ED01 | 字/实物/真人轮换，快之后敢停 |
| 控制台看不清、界面只会平移 | MG01 | 聚焦某次操作，看到反馈后再离开 |
| 活泼但想避免无目的飞来飞去 | MG02 | 从全局进入编辑对象，动作改变内容，再展示结果 |
| 字和表情永远上下浮动 | MV01 | 词义转成动作，有进入、变化、落定 |
| 只有背景音乐 | SD01（需试听） | 辨认前景、环境、过渡的不同作用；不能据抽帧评价音效 |

## 把观察变成制作决策

先读相应拆解卡、播放短片，必要时回原片。记录“参考ID / 源秒数 / 观察 / 本片怎么做 / 如何判断有效”。每种效果至少有一个观众可感知的目的，例如目光到达注册按钮、看见任务进入运行、听到反应落点。不要写泛泛的“高级感、增加炫酷”。

先用自己的原片做约8–12秒代表段落，包含真实操作、一次有意义的动效和关键声音。与参考正常速度对照：

- 切换由什么触发，观众有没有看清结果？
- 动作有没有预备、变化、落定，还是一直飘？
- 真人/界面/文字的景别和信息量有没有变化？
- 声音能否强调动作、区分前后景，有没有压住人声？

代表段落成立再扩展。截图卡、复杂操作和真人关键句可以稳定停留，不为了快剪破坏理解。普通中文字幕保持大、正常、可读；创意标题与正文字幕分开设计。像素场景仍需另找连贯交互与角色表演实例，本库文字MV不能证明已经达到游戏实况质量。

## 取材与核验

新参考要有作者/品牌、来源、可播放短片、对应源时间、具体动作观察、适用与不适用范围。转载者与原作者分开登记；未知就写未知。优先官方网站和作者账号；登录阻挡时用合法公开同作品来源，不猜下载成功、不提取登录凭据绕过。

`catalog.json`记录审阅范围，`verification.json`记录时长、尺寸、音轨、解码与哈希。抽帧只能支持画面观察；无耳听能力时记录“待试听”，不能把响度或波形等同听感。当前SD01属于带音轨的学习候选，尚未成为已试听认可的音效标杆。

片段是参考观看副本，允许缩小以便携带，**不能拿来当产品成片素材或放大充4K**。正式制作仍使用自己的原MOV与原始UI。学习动作机制和节奏，不搬品牌画面、他人歌曲、表情或版式去冒充原创。第三方片段仅在本地参考库保存；公开仓库默认带来源链接、目录和拆解，随包公开媒体前核对许可。

## 给云端Agent的交接

完整目录用相对路径：SKILL → docs/exemplars → examples/INDEX → cards/media。只上传一个SKILL.md不会带走范例。任务开头让Agent报告实际读到的版本、选定ID、可访问媒体与审阅限制；缺视频时至少读拆解卡并打开来源，不能只看名称说已学习。

若任务允许上传第三方学习片段，保留目录结构携带所选片段；否则只交链接与分析。原片储存在本机相邻“参考视频原片”目录，不是云端依赖。重建短片用：

```text
python scripts/build_reference_clips.py --source-dir <参考视频原片目录>
```

这轮只验证了参考库可用与技能导航完整；尚未用新作品证明72分问题已经改善。
